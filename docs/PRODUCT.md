# Product

Phone Detox is an Android-first, privacy-first replacement Home launcher that reduces unconscious phone use while preserving useful smartphone capabilities.

## MVP promise

The launcher provides a calm, searchable text list of installed launchable apps. People can favourite useful apps, hide distracting apps, and reverse either choice locally without an account.

## Principles

- Add deliberate friction without trapping the user.
- Keep configuration and installed-app inventory on-device.
- Request only capabilities required by active, explained features.
- Use no ads, analytics, network communication, or account for the Android MVP.
- Prefer a €9.99 lifetime purchase when monetization is added in its own milestone.
